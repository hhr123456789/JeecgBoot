## 三、功能需求分析

### 3.1 告警模板设置 (Alarm_Settings)

**功能定位**: 定义通用的告警配置模板，可被多个规则引用

**核心功能**:
1. 模板基本信息管理（名称、类型、能源类型、设备类型/监控范围）
2. 结构化的告警条件配置（监控指标、比较方式、默认阈值、持续时长、检查频率）
3. 默认告警设置（告警级别、通知方式、静默期）
4. 模板使用情况统计（被多少规则引用）
5. 基于模板快速创建规则

**数据字段**:
| 字段 | 说明 | 类型 |
|------|------|------|
| id | 主键ID | VARCHAR(64) |
| name | 模板名称 | VARCHAR(100) |
| type | 模板类型 | VARCHAR(20): device/energy |
| energy_type | 能源类型 | VARCHAR(10): 1-电,2-水,8-天然气,5-压缩空气 |
| device_type | 设备类型（设备告警用） | VARCHAR(50) |
| target_scope | 监控范围（能源告警用） | VARCHAR(50) |
| conditions | 告警条件配置JSON | TEXT |
| level | 默认告警级别 | VARCHAR(20): high/medium/low |
| notify_methods | 默认通知方式JSON | VARCHAR(200) |
| silence_period | 默认静默期（分钟） | INT |
| description | 模板说明 | VARCHAR(500) |
| dept_id | 所属部门ID | VARCHAR(64) |
| status | 状态 | TINYINT: 1-启用,0-禁用 |
| create_by | 创建人 | VARCHAR(50) |
| create_time | 创建时间 | DATETIME |
| update_by | 更新人 | VARCHAR(50) |
| update_time | 更新时间 | DATETIME |

### 3.2 告警规则设置 (Alarm_Rules_Settings)

**功能定位**: 定义具体的告警规则，可基于模板创建或自定义创建

**核心功能**:
1. 规则基本信息管理（名称、类型、能源类型、监控对象）
2. 结构化的告警条件配置（支持多条件，满足任一即告警）
3. 告警设置（级别、通知方式、通知人员、静默期）
4. 规则启用/禁用状态管理
5. 基于模板创建规则（继承模板配置）
6. 显示规则关联的模板来源

**数据字段**:
| 字段 | 说明 | 类型 |

### 3.3 告警条件数据结构

```typescript
interface AlarmCondition {
  metric: string;          // 监控指标
  operator: string;        // 比较运算符: gt/gte/lt/lte/eq/ne/between
  threshold: number;       // 阈值
  thresholdMax?: number;   // 最大阈值（区间比较用）
  unit: string;            // 单位
  duration: number;        // 持续时长（分钟）
  checkInterval: number;   // 检查频率（分钟）
}
```

## 四、数据库设计

### 4.1 告警模板表 (tb_alarm_template)

```sql
CREATE TABLE `tb_alarm_template` (
  `id` varchar(64) NOT NULL COMMENT '主键ID',
  `name` varchar(100) NOT NULL COMMENT '模板名称',
  `type` varchar(20) NOT NULL COMMENT '模板类型：device-设备告警,energy-能源告警',
  `energy_type` varchar(10) NOT NULL COMMENT '能源类型：1-电,2-水,8-天然气,5-压缩空气',
  `device_type` varchar(50) DEFAULT NULL COMMENT '设备类型（设备告警用）',
  `target_scope` varchar(50) DEFAULT NULL COMMENT '监控范围（能源告警用）：department/line/workshop/device',
  `conditions` text NOT NULL COMMENT '告警条件配置JSON数组',
  `level` varchar(20) NOT NULL DEFAULT 'medium' COMMENT '默认告警级别：high/medium/low',
  `notify_methods` varchar(200) DEFAULT NULL COMMENT '默认通知方式JSON数组',
  `silence_period` int(11) DEFAULT '60' COMMENT '默认静默期（分钟）',
  `description` varchar(500) DEFAULT NULL COMMENT '模板说明',
  `dept_id` varchar(64) DEFAULT NULL COMMENT '所属部门ID',
  `status` tinyint(1) DEFAULT '1' COMMENT '状态：1-启用,0-禁用',
  `create_by` varchar(50) DEFAULT NULL COMMENT '创建人',
  `create_time` datetime DEFAULT NULL COMMENT '创建时间',
  `update_by` varchar(50) DEFAULT NULL COMMENT '更新人',
  `update_time` datetime DEFAULT NULL COMMENT '更新时间',
  PRIMARY KEY (`id`),
  KEY `idx_type` (`type`),
  KEY `idx_energy_type` (`energy_type`),
  KEY `idx_status` (`status`),
  KEY `idx_dept_id` (`dept_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='告警模板表';
```

### 6.3 Controller 示例

#### AlarmTemplateController.java
```java
package org.jeecg.modules.energy.controller.alarm;

import com.baomidou.mybatisplus.core.metadata.IPage;
import io.swagger.annotations.Api;
import io.swagger.annotations.ApiOperation;
import lombok.extern.slf4j.Slf4j;
import org.jeecg.common.api.vo.Result;
import org.jeecg.modules.energy.entity.alarm.AlarmTemplate;
import org.jeecg.modules.energy.service.IAlarmTemplateService;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.*;

@Api(tags = "告警模板管理")
@RestController
@RequestMapping("/energy/alarm/template")
@Slf4j
public class AlarmTemplateController {

    @Autowired
    private IAlarmTemplateService alarmTemplateService;

    @ApiOperation("分页查询模板列表")
    @GetMapping("/list")
    public Result<?> list(
            @RequestParam(required = false) String name,
            @RequestParam(required = false) String type,
            @RequestParam(required = false) String energyType,
            @RequestParam(required = false) Integer status,
            @RequestParam(defaultValue = "1") Integer pageNo,
            @RequestParam(defaultValue = "10") Integer pageSize) {
        IPage<AlarmTemplate> page = alarmTemplateService.queryPageList(
            name, type, energyType, status, pageNo, pageSize);
        return Result.OK(page);
    }

    @ApiOperation("新增模板")
    @PostMapping("/add")
    public Result<?> add(@RequestBody AlarmTemplate template) {
        alarmTemplateService.saveTemplate(template);
        return Result.OK("保存成功");
    }

    @ApiOperation("编辑模板")
    @PutMapping("/edit")
    public Result<?> edit(@RequestBody AlarmTemplate template) {
        alarmTemplateService.updateTemplate(template);
        return Result.OK("更新成功");
    }

    @ApiOperation("删除模板")
    @DeleteMapping("/delete")
    public Result<?> delete(@RequestParam String id) {
        return alarmTemplateService.deleteTemplate(id);
    }

    @ApiOperation("查询模板使用情况")
    @GetMapping("/usage")
    public Result<?> usage(@RequestParam String id) {
        return Result.OK(alarmTemplateService.getTemplateUsage(id));
    }

    @ApiOperation("获取模板选项列表")
    @GetMapping("/options")
    public Result<?> options() {
        return Result.OK(alarmTemplateService.getTemplateOptions());
    }
}
```
