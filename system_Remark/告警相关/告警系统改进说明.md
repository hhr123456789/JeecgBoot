# 告警系统前端改进说明文档

## 一、改进概述

本次改进针对能源管理系统的告警模块进行了全面优化，解决了以下核心问题：

1. **通用性不足**：原系统仅支持设备告警和用电告警，无法适配天然气、水、压缩空气等其他能源类型
2. **规则配置不灵活**：告警条件采用文本输入，后端难以解析和执行
3. **功能耦合**：模板和规则混淆，缺乏清晰的业务分层

## 二、主要改进内容

### 2.1 告警规则设置 (Alarm_Rules_Settings)

**文件位置**: `jeecgboot-vue3/src/views/EnergyAlarm/Alarm_Rules_Settings/index.vue`

#### 核心改进点

1. **支持多种能源类型**
   - 电力 (energyType: "1")
   - 水 (energyType: "2")
   - 天然气 (energyType: "8")
   - 压缩空气 (energyType: "5")

2. **统一的告警类型体系**
   ```typescript
   ruleType: 'device' | 'energy'  // 设备告警 vs 能源告警
   ```

3. **结构化的告警条件配置**
   - 替代原来的文本输入方式
   - 采用可视化配置界面
   - 后端可直接解析执行

   ```typescript
   interface RuleCondition {
     metric: string;          // 监控指标（如：day_consumption, device_current）
     operator: string;        // 比较运算符（gt, gte, lt, lte, eq, ne, between）
     threshold: number;       // 阈值
     thresholdMax?: number;   // 最大阈值（区间比较用）
     unit: string;            // 单位（自动根据能源类型和指标匹配）
     duration: number;        // 持续时长（分钟）
     checkInterval: number;   // 检查频率（分钟）
   }
   ```

4. **丰富的监控指标**
   
   **设备运行指标**：
   - `device_status` - 设备状态
   - `device_current` - 运行电流
   - `device_voltage` - 运行电压
   - `device_power` - 运行功率
   - `device_temperature` - 设备温度
   - `device_pressure` - 设备压力

   **能源消耗指标**：
   - `hour_consumption` - 小时用量
   - `day_consumption` - 日用量
   - `month_consumption` - 月用量
   - `consumption_rate` - 用量变化率
   - `unit_consumption` - 单位产品能耗
   - `cost` - 能源费用

5. **灵活的告警配置**
   - 支持多条件组合（满足任一即告警）
   - 告警级别：高、中、低
   - 通知方式：系统通知、邮件、短信、微信
   - 通知人员：多选
   - 静默期设置：避免重复告警

6. **智能化功能**
   - 单位自动匹配（根据能源类型和指标）
   - 表单验证完善
   - 交互体验优化

@Service
public class AlarmRuleEngine {
    
    /**
     * 执行告警规则检查
     */
    public void executeRuleCheck(AlarmRule rule) {
        List<RuleCondition> conditions = parseConditions(rule.getConditions());
        
        for (RuleCondition condition : conditions) {
            // 根据监控指标获取当前值
            BigDecimal currentValue = getCurrentValue(
                rule.getRuleType(),
                rule.getEnergyType(),
                condition.getMetric()
            );
            
            // 判断是否满足告警条件
            if (checkCondition(currentValue, condition)) {
                // 检查持续时长
                if (checkDuration(rule, condition)) {
                    // 检查静默期
                    if (!inSilencePeriod(rule)) {
                        // 触发告警
                        triggerAlarm(rule, condition, currentValue);
                    }
                }
            }
        }
    }
    
    /**
     * 解析告警条件
     */
    private List<RuleCondition> parseConditions(String conditionsJson) {
        // 解析JSON为条件对象列表
        return JSON.parseArray(conditionsJson, RuleCondition.class);
    }
    
    /**
     * 获取当前监控值
     */
    private BigDecimal getCurrentValue(String ruleType, String energyType, String metric) {
        // 根据规则类型、能源类型和监控指标，从InfluxDB或MySQL查询当前值
        if ("device".equals(ruleType)) {
            // 查询设备运行数据
            return getDeviceMetricValue(metric);
        } else {
            // 查询能源消耗数据
            return getEnergyMetricValue(energyType, metric);
        }
    }
    
    /**
     * 检查条件是否满足
     */
    private boolean checkCondition(BigDecimal currentValue, RuleCondition condition) {
        BigDecimal threshold = condition.getThreshold();
        
        switch (condition.getOperator()) {

     * 触发告警

    @Autowired
    private AlarmRuleService alarmRuleService;
    
    @Autowired
    private AlarmRuleEngine alarmRuleEngine;
    
    /**
     * 每分钟执行一次规则检查
     */
    @Scheduled(cron = "0 * * * * ?")
    public void checkAlarmRules() {
        // 查询所有启用的规则
        List<AlarmRule> rules = alarmRuleService.getEnabledRules();
        
        for (AlarmRule rule : rules) {
            try {
                // 检查规则的检查频率
                if (shouldCheck(rule)) {
                    alarmRuleEngine.executeRuleCheck(rule);
                }
            } catch (Exception e) {
                log.error("规则检查异常: {}", rule.getName(), e);
            }
        }
