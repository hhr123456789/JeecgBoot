## 🎯 核心设计亮点

### 1. 业务价值
- **单位产品能耗**: 核心指标,直接反映产品能效
- **合格率关联**: 将能耗与产品质量结合分析
- **环比分析**: 趋势变化一目了然 (红升绿降)
- **多维度对比**: 产品、时间、工序多角度分析

### 2. 技术特点
- **组件复用**: 图表组件可复用
- **类型安全**: TypeScript 全覆盖
- **响应式设计**: Grid 布局自适应
- **色彩系统**: 语义化颜色 (蓝/绿/黄/红)

### 3. 数据模型
```
产品分类树
  └─ 产品信息 (tb_product_info)
      ├─ 产品产量 (tb_product_production)
      ├─ 工序关联 (tb_product_process_rel)
      │   └─ 仪表数据 (tb_module)
      │       └─ 能耗统计 (tb_ep_equ_energy_*)
      └─ 产品能耗统计 (tb_product_energy_consumption)
          └─ 单位产品能耗 = 总能耗 ÷ 合格产量
```
