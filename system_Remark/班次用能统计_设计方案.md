# 班次用能统计功能设计方案

## 一、需求分析

### 1.1 前端页面分析 (Shift_Energy/index.vue)

当前前端页面是静态页面，包含以下组件：
- 左侧部门树（硬编码数据）
- 时间维度选择（日/月/年）
- 班次选择（全部班次/早班/中班/晚班）
- 统计卡片（总能耗、早班能耗、中班能耗、晚班能耗）
- 趋势图和饼图
- 数据表格

### 1.2 与班组用能统计的区别

| 功能 | 班组用能统计 (Team_Energy) | 班次用能统计 (Shift_Energy) |
|------|---------------------------|---------------------------|
| 统计维度 | 按班组统计 | 按班次（早班/中班/晚班）统计 |
| 筛选条件 | 选择班组 | 选择班次类型 |
| 数据来源 | 班组关联的仪表 | 班次时间段内的仪表数据 |
| 左侧维度 | DimensionTree 组件 | 需要统一使用 DimensionTree |

### 1.3 现有数据库表分析

1. **tb_team_shift_schedule** - 班组排班表（已有班次时间信息）
   - shift_type: 班次类型（早班/中班/晚班/夜班）
   - start_time: 开始时间
   - end_time: 结束时间
   - shift_date: 排班日期

2. **tb_team_dimension_relation** - 班组维度关联（已有仪表关联）
   - module_ids: 关联的仪表ID列表

3. **tb_ep_equ_energy_daycount** - 日能耗统计（已有能耗数据）

## 二、设计方案

### 2.1 数据模型设计

**结论：不需要新建表，复用现有表结构**

班次用能统计可以通过以下方式实现：
1. 从 `tb_team_shift_schedule` 获取班次时间定义
2. 从 `tb_team_dimension_relation` 获取维度关联的仪表
3. 从 `tb_ep_equ_energy_daycount` 按时间段汇总能耗

### 2.2 班次能耗计算逻辑

```
班次能耗 = SUM(该班次时间段内所有关联仪表的能耗)

计算步骤：
1. 根据维度(dimension_code)获取关联的仪表列表(module_ids)
2. 根据班次类型获取时间段(start_time, end_time)
3. 查询该时间段内仪表的能耗数据
4. 按班次类型汇总
```

### 2.3 API 接口设计

#### 2.3.1 获取班次统计数据
```
GET /energy/shiftEnergy/getStatistics
参数:
  - dimensionCode: 维度编码
  - dimensionType: 维度类型
  - timeUnit: 时间单位 (day/month/year)
  - date: 日期
  - shiftType: 班次类型 (all/morning/middle/night)
  - energyType: 能源类型

返回:
{
  totalConsumption: 总能耗,
  morningConsumption: 早班能耗,
  middleConsumption: 中班能耗,
  nightConsumption: 晚班能耗,
  totalCost: 总费用,
  totalCarbon: 碳排放,
  totalCoal: 折标煤
}
```

```
GET /energy/shiftEnergy/getTrendData
参数: 同上
```

### 3.2 核心查询逻辑

```java
// 1. 获取维度关联的仪表
List<String> moduleIds = getModuleIdsByDimension(dimensionCode, dimensionType);

// 2. 获取班次时间定义
Map<String, TimeRange> shiftTimeRanges = getShiftTimeRanges();
// 早班: 00:00 - 08:00
// 中班: 08:00 - 16:00
// 晚班: 16:00 - 24:00

// 3. 查询能耗数据并按班次汇总
// 由于日统计表没有小时粒度，需要按整天统计
// 或者从 InfluxDB 查询小时粒度数据
```

### 3.3 班次时间定义

根据 `tb_team_shift_schedule` 表的数据：
- 早班: 00:00 - 12:00
- 中班: 12:00 - 18:00
- 晚班/夜班: 18:00 - 24:00

**注意**: 由于 `tb_ep_equ_energy_daycount` 是日粒度统计，无法精确到小时。
建议方案：
1. 简化版：按整天统计，班次占比按固定比例分配
2. 精确版：从 InfluxDB 查询小时粒度数据
