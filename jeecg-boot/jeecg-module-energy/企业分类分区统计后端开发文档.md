# 企业分类分区统计功能后端开发文档

## 一、功能概述

企业分类分区统计功能主要实现对企业的能源消耗按部门和能源类型进行统计和分析，包括：

1. 按部门树形结构筛选统计
2. 按时间维度查询（日/月/年）
3. 按能源类型筛选（电能/水能/燃气/全部）
4. 统计卡片显示（总能耗、分能源消耗）
5. 图表分析（饼图占比、折线图趋势）
6. 详细数据表格展示

package org.jeecg.modules.energy.controller.classification;

## 八、实现要点

### 8.1 数据查询逻辑
1. 根据部门编码查询当前部门及子部门数据
2. 根据能源类型筛选数据（all表示全部）
3. 根据时间维度聚合数据
4. 计算各能源类型的消耗占比
5. 计算碳排放和标准煤当量

### 8.2 性能优化
1. 使用索引优化查询性能
2. 分页查询大量数据
3. 缓存常用配置数据
4. 异步处理大数据导出

### 8.3 数据安全
1. 参数校验和SQL注入防护
2. 部门数据权限控制
3. 敏感数据脱敏处理
