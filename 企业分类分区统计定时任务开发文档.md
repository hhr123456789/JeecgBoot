# 企业分类分区统计定时任务开发文档

## 1. 项目概述

### 1.1 需求描述
为企业的分类分区统计功能设计一个定时任务，从实时统计表每5分钟自动更新分区分类相关的表，实现数据的自动化聚合和统计，无需手工造数据插入数据库。

### 1.2 功能目标
- **数据来源**: 实时统计表 `tb_ep_equ_energy_daycount`
- **数据目标**: 企业分类分区统计汇总表 `tb_energy_classification_summary`
- **更新频率**: 每5分钟执行一次
- **数据聚合**: 按部门编码(`sysOrgCode`) + 能源类型(`energyType`) + 时间维度聚合

## 2. 数据结构分析

### 2.1 源数据表 (实时统计表)

#### tb_ep_equ_energy_daycount (日统计表)
```sql
- id: 主键
- module_id: 仪表编号
- dt: 统计日期
- energy_count: 能耗值
- strat_count: 开始值
- end_count: 结束值
- start_cusp_count/end_cusp_count/cusp_count: 尖时段
- start_peak_count/end_peak_count/peak_count: 峰时段
- start_level_count/end_level_count/level_count: 平时段
- start_valley_count/end_valley_count/valley_count: 谷时段
```

#### tb_module (仪表基础信息表)
```sql
- id: 主键
- module_id: 仪表编号
- module_name: 仪表名称
- energy_type: 能源类型 (1:电能 2:水能 3:燃气)
- sys_org_code: 所属部门编码 (用于分类分区)
- isaction: 是否启用
```

### 2.2 目标数据表 (分类分区统计表)

#### tb_energy_classification_summary
```sql
- id: 主键ID
- org_code: 部门编码 (对应 sys_org_code)
- org_name: 部门名称
- parent_org_code: 父级部门编码
- energy_type: 能源类型
- energy_type_name: 能源类型名称
- stat_date: 统计日期
- stat_month: 统计月份
- stat_year: 统计年份
- time_dimension: 时间维度 (day/month/year)
- total_consumption: 总消耗量
- total_cost: 总费用
- carbon_emission: 碳排放量
- standard_coal: 标准煤当量
- peak_consumption/peak_cost: 峰时段消耗/费用
- flat_consumption/flat_cost: 平时段消耗/费用
- valley_consumption/valley_cost: 谷时段消耗/费用
- meter_count: 仪表数量
```

### 2.3 能源类型配置表

#### tb_energy_type_config
```sql
- id: 主键
- energy_type: 能源类型编码
- energy_name: 能源类型名称
- energy_unit: 计量单位
- price_per_unit: 单价
- carbon_factor: 碳排放系数
- coal_factor: 标准煤系数
```

## 3. 技术方案设计

### 3.1 定时任务架构
```
企业分类分区统计定时任务 (EnergyClassificationSyncJob)
├── 数据查询模块
│   ├── 查询实时统计数据
│   ├── 查询仪表配置信息
│   └── 查询能源类型配置
├── 数据聚合模块
│   ├── 按部门+能源类型分组
│   ├── 按时间维度聚合 (日/月/年)
│   └── 计算各项指标
├── 数据计算模块
│   ├── 费用计算 (消耗量 × 单价)
│   ├── 碳排放计算 (消耗量 × 碳排放系数)
│   └── 标准煤当量计算 (消耗量 × 标准煤系数)
└── 数据更新模块
    ├── 插入新记录
    └── 更新现有记录
```

### 3.2 数据聚合逻辑

#### 分组维度
1. **部门维度**: `sys_org_code` (部门编码)
2. **能源类型维度**: `energy_type` (1:电能 2:水能 3:燃气)
3. **时间维度**: `time_dimension` (day/month/year)

#### 聚合规则
- **总消耗量**: Σ energy_count
- **峰时段消耗**: Σ peak_count (仅电力)
- **平时段消耗**: Σ level_count (仅电力)
- **谷时段消耗**: Σ valley_count (仅电力)
- **仪表数量**: COUNT(DISTINCT module_id)
- **总费用**: 总消耗量 × price_per_unit
- **碳排放量**: 总消耗量 × carbon_factor
- **标准煤当量**: 总消耗量 × coal_factor

### 3.3 时间维度处理
- **日维度**: 按每日聚合数据
- **月维度**: 按每月聚合数据
- **年维度**: 按每年聚合数据

### 4.2 数据查询策略
1. **实时数据查询**:
   - 查询 `tb_ep_equ_energy_daycount` 表
   - 限定时间范围和启用状态的仪表

2. **仪表信息查询**:
   - 查询 `tb_module` 表获取 `sys_org_code` 和 `energy_type`
   - 关联实时数据进行部门分类

3. **能源配置查询**:
   - 查询 `tb_energy_type_config` 获取价格和系数
   - 用于费用和碳排放计算

### 4.3 数据更新策略
1. **新增数据**:
   - 查找不存在的记录，直接插入

2. **更新数据**:
   - 查找已存在的记录，更新统计值

3. **数据去重**:
   - 使用 `org_code + energy_type + time_dimension + stat_date` 作为唯一标识

```java
private void syncDailyData() {
    log.info("开始同步日维度数据...");
    
    // 获取昨天和今天的数据
    Date yesterday = getYesterday();
    Date today = getToday();
    
    // 查询昨天的统计数据
    List<TbEpEquEnergyDaycount> dailyData = queryDailyData(yesterday);
    
    // 按部门+能源类型分组聚合
    Map<String, List<TbEpEquEnergyDaycount>> groupedData = groupByOrgAndEnergyType(dailyData);
    
    // 处理每个分组
    for (Map.Entry<String, List<TbEpEquEnergyDaycount>> entry : groupedData.entrySet()) {
        String groupKey = entry.getKey();
        List<TbEpEquEnergyDaycount> dataList = entry.getValue();
        
        // 解析部门编码和能源类型
        String[] parts = groupKey.split("_");
        String orgCode = parts[0];
        Integer energyType = Integer.parseInt(parts[1]);
        
        // 聚合数据
        ClassificationSummaryVO summary = aggregateData(dataList, energyType);
        
        // 更新到分类统计表
        updateClassificationSummary(orgCode, energyType, "day", yesterday, summary);
    }
    
    log.info("日维度数据同步完成，共处理 {} 个分组", groupedData.size());
}
```

#### 5.1.3 数据聚合方法
```java
private ClassificationSummaryVO aggregateData(List<TbEpEquEnergyDaycount> dataList, Integer energyType) {
    ClassificationSummaryVO summary = new ClassificationSummaryVO();
    
    BigDecimal totalConsumption = BigDecimal.ZERO;
    BigDecimal totalCost = BigDecimal.ZERO;
    BigDecimal totalCarbon = BigDecimal.ZERO;
    BigDecimal totalStandardCoal = BigDecimal.ZERO;
    
    BigDecimal peakConsumption = BigDecimal.ZERO;
    BigDecimal flatConsumption = BigDecimal.ZERO;
    BigDecimal valleyConsumption = BigDecimal.ZERO;
    BigDecimal cuspConsumption = BigDecimal.ZERO;
    
    Set<String> moduleIds = new HashSet<>();
    
    for (TbEpEquEnergyDaycount data : dataList) {
        // 累计消耗量
        if (data.getEnergyCount() != null) {
            totalConsumption = totalConsumption.add(data.getEnergyCount());
        }
        
        // 累计分时数据
        if (data.getPeakCount() != null) {
            peakConsumption = peakConsumption.add(data.getPeakCount());
        }
        if (data.getLevelCount() != null) {
            flatConsumption = flatConsumption.add(data.getLevelCount());
        }
        if (data.getValleyCount() != null) {
            valleyConsumption = valleyConsumption.add(data.getValleyCount());
        }
        if (data.getCuspCount() != null) {
            cuspConsumption = cuspConsumption.add(data.getCuspCount());
        }
        
        // 记录仪表ID
        if (data.getModuleId() != null) {
            moduleIds.add(data.getModuleId());
        }
    }
    
    // 获取能源类型配置
    EnergyTypeConfigVO config = getEnergyTypeConfig(energyType);
    
    if (config != null) {
        // 计算费用
        if (config.getPricePerUnit() != null) {
            totalCost = totalConsumption.multiply(config.getPricePerUnit());
        }
        
        // 计算碳排放
        if (config.getCarbonFactor() != null) {
            totalCarbon = totalConsumption.multiply(config.getCarbonFactor());
        }
        
        // 计算标准煤当量
        if (config.getCoalFactor() != null) {
            totalStandardCoal = totalConsumption.multiply(config.getCoalFactor());
        }
    }
    
    // 设置聚合结果
    summary.setTotalConsumption(totalConsumption);
    summary.setTotalCost(totalCost);
    summary.setCarbonEmission(totalCarbon);
    summary.setStandardCoal(totalStandardCoal);
    summary.setPeakConsumption(peakConsumption);
    summary.setFlatConsumption(flatConsumption);
    summary.setValleyConsumption(valleyConsumption);
    summary.setCuspConsumption(cuspConsumption);
    summary.setMeterCount(moduleIds.size());
    
    return summary;
}
```

```java
@Mapper
public interface TbEnergyClassificationSummaryMapper extends BaseMapper<TbEnergyClassificationSummary> {
    
    /**
     * 根据条件查询分类统计汇总数据
     */
    @Select("""
        SELECT * FROM tb_energy_classification_summary 
        WHERE org_code = #{orgCode} 
        AND energy_type = #{energyType} 
        AND time_dimension = #{timeDimension} 
        AND stat_date = #{statDate}
    """)
    TbEnergyClassificationSummary selectByCondition(
        @Param("orgCode") String orgCode,
        @Param("energyType") Integer energyType,
        @Param("timeDimension") String timeDimension,
        @Param("statDate") Date statDate
    );
    
    /**
     * 按部门编码、能源类型、时间维度分组统计
     */
    @Select("""
        SELECT 
            m.sys_org_code as org_code,
            m.energy_type,
            DATE(d.dt) as stat_date,
            DATE_FORMAT(d.dt, '%Y-%m') as stat_month,
            DATE_FORMAT(d.dt, '%Y') as stat_year,
            SUM(d.energy_count) as total_consumption,
            SUM(d.peak_count) as peak_consumption,
            SUM(d.level_count) as flat_consumption,
            SUM(d.valley_count) as valley_consumption,
            SUM(d.cusp_count) as cusp_consumption,
            COUNT(DISTINCT d.module_id) as meter_count
        FROM tb_ep_equ_energy_daycount d
        INNER JOIN tb_module m ON d.module_id = m.module_id
        WHERE m.isaction = 'Y'
        AND d.dt >= #{startDate} 
        AND d.dt <= #{endDate}
        GROUP BY m.sys_org_code, m.energy_type, DATE(d.dt)
    """)
    List<ClassificationStatisticsVO> selectStatisticsGroupByOrgAndEnergyType(
        @Param("startDate") Date startDate,
        @Param("endDate") Date endDate
    );
}
```

#### 5.3.2 服务实现类
```java
@Service
@Slf4j
public class EnergyClassificationSyncServiceImpl implements IEnergyClassificationSyncService {
    
    @Autowired
    private TbModuleMapper moduleMapper;
    
    @Autowired
    private TbEpEquEnergyDaycountMapper daycountMapper;
    
    @Autowired
    private TbEnergyClassificationSummaryMapper summaryMapper;
    
    @Autowired
    private TbEnergyTypeConfigMapper energyTypeConfigMapper;
    
    @Autowired
    private TbEpEquEnergyMonthcountMapper monthcountMapper;
    
    @Autowired
    private TbEpEquEnergyYearcountMapper yearcountMapper;
    
    @Override
    public void syncDailyData(Date targetDate) {
        log.info("开始同步 {} 的日维度分类数据", formatDate(targetDate));
        
        try {
            // 计算时间范围（前一天）
            Calendar cal = Calendar.getInstance();
            cal.setTime(targetDate);
            cal.add(Calendar.DAY_OF_MONTH, -1);
            Date startDate = getStartOfDay(cal.getTime());
            Date endDate = getEndOfDay(cal.getTime());
            
            // 查询统计数据
            List<ClassificationStatisticsVO> statisticsList = 
                summaryMapper.selectStatisticsGroupByOrgAndEnergyType(startDate, endDate);
            
            log.info("查询到 {} 条统计数据", statisticsList.size());
            
            // 处理每条统计记录
            for (ClassificationStatisticsVO statistics : statisticsList) {
                processDailyStatistics(statistics, cal.getTime());
            }
            
            log.info("日维度数据同步完成");
        } catch (Exception e) {
            log.error("同步日维度数据失败", e);
            throw new RuntimeException("同步日维度数据失败", e);
        }
    }
    
    private void processDailyStatistics(ClassificationStatisticsVO statistics, Date targetDate) {
        try {
            // 获取能源类型配置
            EnergyTypeConfigVO config = getEnergyTypeConfig(statistics.getEnergyType());
            
            // 计算费用、碳排放、标准煤当量
            BigDecimal totalCost = calculateCost(statistics.getTotalConsumption(), config);
            BigDecimal carbonEmission = calculateCarbonEmission(statistics.getTotalConsumption(), config);
            BigDecimal standardCoal = calculateStandardCoal(statistics.getTotalConsumption(), config);
            
            // 计算峰谷平时段费用
            BigDecimal peakCost = calculateCost(statistics.getPeakConsumption(), config);
            BigDecimal flatCost = calculateCost(statistics.getFlatConsumption(), config);
            BigDecimal valleyCost = calculateCost(statistics.getValleyConsumption(), config);
            
            // 获取部门名称
            String orgName = getOrgName(statistics.getOrgCode());
            
            // 构建汇总记录
            TbEnergyClassificationSummary summary = buildSummaryRecord(
                statistics, config, totalCost, carbonEmission, standardCoal,
                peakCost, flatCost, valleyCost, orgName, targetDate
            );
            
            // 插入或更新记录
            upsertClassificationSummary(summary);
            
        } catch (Exception e) {
            log.error("处理日统计数据失败: orgCode={}, energyType={}", 
                statistics.getOrgCode(), statistics.getEnergyType(), e);
        }
    }
    
    private TbEnergyClassificationSummary buildSummaryRecord(
        ClassificationStatisticsVO statistics,
        EnergyTypeConfigVO config,
        BigDecimal totalCost,
        BigDecimal carbonEmission,
        BigDecimal standardCoal,
        BigDecimal peakCost,
        BigDecimal flatCost,
        BigDecimal valleyCost,
        String orgName,
        Date targetDate
    ) {
        TbEnergyClassificationSummary summary = new TbEnergyClassificationSummary();
        
        // 设置基础信息
        summary.setOrgCode(statistics.getOrgCode());
        summary.setOrgName(orgName);
        summary.setParentOrgCode(getParentOrgCode(statistics.getOrgCode()));
        summary.setEnergyType(statistics.getEnergyType());
        summary.setEnergyTypeName(config != null ? config.getEnergyName() : getEnergyTypeName(statistics.getEnergyType()));
        summary.setStatDate(targetDate);
        summary.setStatMonth(formatDate(targetDate, "yyyy-MM"));
        summary.setStatYear(formatDate(targetDate, "yyyy"));
        summary.setTimeDimension("day");
        
        // 设置统计数据
        summary.setTotalConsumption(statistics.getTotalConsumption() != null ? statistics.getTotalConsumption() : BigDecimal.ZERO);
        summary.setTotalCost(totalCost);
        summary.setCarbonEmission(carbonEmission);
        summary.setStandardCoal(standardCoal);
        summary.setPeakConsumption(statistics.getPeakConsumption() != null ? statistics.getPeakConsumption() : BigDecimal.ZERO);
        summary.setPeakCost(peakCost);
        summary.setFlatConsumption(statistics.getFlatConsumption() != null ? statistics.getFlatConsumption() : BigDecimal.ZERO);
        summary.setFlatCost(flatCost);
        summary.setValleyConsumption(statistics.getValleyConsumption() != null ? statistics.getValleyConsumption() : BigDecimal.ZERO);
        summary.setValleyCost(valleyCost);
        summary.setCuspConsumption(statistics.getCuspConsumption() != null ? statistics.getCuspConsumption() : BigDecimal.ZERO);
        summary.setMeterCount(statistics.getMeterCount() != null ? statistics.getMeterCount() : 0);
        
        return summary;
    }
    
    private void upsertClassificationSummary(TbEnergyClassificationSummary summary) {
        // 查询是否已存在记录
        TbEnergyClassificationSummary existing = summaryMapper.selectByCondition(
            summary.getOrgCode(),
            summary.getEnergyType(),
            summary.getTimeDimension(),
            summary.getStatDate()
        );
        
        if (existing != null) {
            // 更新现有记录
            summary.setId(existing.getId());
            summaryMapper.updateById(summary);
            log.debug("更新分类统计记录: orgCode={}, energyType={}, date={}", 
                summary.getOrgCode(), summary.getEnergyType(), summary.getStatDate());
        } else {
            // 插入新记录
            summary.setId(UUID.randomUUID().toString());
            summaryMapper.insert(summary);
            log.debug("创建分类统计记录: orgCode={}, energyType={}, date={}", 
                summary.getOrgCode(), summary.getEnergyType(), summary.getStatDate());
        }
    }
}
```
