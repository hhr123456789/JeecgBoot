# 企业分类分区统计功能重构设计文档

## 一、项目背景

### 1.1 当前问题分析

基于对现有企业分类分区统计功能的分析，发现以下问题需要重新设计和修改:

#### 现有实现的主要问题

1. **维度树数据来源问题**
   - 现状: 前端调用 `/energy/classification/getOrgTree` 接口，但后端并未真正从数据库 `sys_depart` 表查询数据
   - 问题: 维度树数据是硬编码或静态数据，无法反映实际的部门组织结构
   - 需求: 需要改为从 `sys_depart` 表动态查询，且只展示到二级维度

2. **能源类型配置表更换**
   - 现状: 使用 `tb_energy_type_config` 表存储能源类型配置、单价、系数等信息
   - 问题: 原表结构不符合新需求
   - 需求: 更换为 `tb_energy_ratio_info` 表，该表包含更完整的能源信息（折标煤系数、碳排放系数等）

3. **能源类型选择逻辑问题**
   - 现状: 能源类型选择固定为"电能、水能、燃气"
   - 问题: 未根据实际选中维度的设备能源类型动态展示
   - 需求: 选择维度后，能源类型下拉框应展示该维度下实际设备的能源类型

4. **缺少部门横向对比功能**
   - 现状: 只有统计汇总数据，无法看到同级部门或设备的对比
   - 问题: 无法直观对比不同部门/设备的能耗情况
   - 需求: 增加横向对比图表和数据展示

5. **定时任务统计维度不完整**
   - 现状: 只统计到部门级别
   - 问题: 无法看到具体设备级别的统计
   - 需求: 需要同时统计部门汇总数据和设备明细数据

### 1.2 参考模块分析

#### 实时数据监控模块 (Real_Monitor)

该模块的优秀实现可作为参考:

1. **动态维度树**
   - 使用 `DimensionTree` 组件
   - 通过 `queryMydimensionTreeList` 接口动态查询 `sys_depart` 表
   - 支持按不同能源类型 (nowtype) 查询对应的维度结构
   - 自动展开到指定级别 (selectLevel=2)

2. **维度与设备关联**
   - 通过 `orgCode` 关联部门和设备
   - 通过 `tb_module` 表的 `sys_org_code` 字段建立关联
   - 根据 `energy_type` 字段区分不同能源类型的设备

3. **能源类型动态识别**
   - 根据选中维度的 `nowtype` 参数查询对应能源类型的设备
   - 电力设备 (nowtype=1或2): 显示详细的电力参数
   - 其他能源设备 (nowtype=3/4/5): 显示对应的能源参数

### 1.3 数据库表结构

#### sys_depart (部门维度表)

维度树的数据来源，核心字段:
- `id`: 主键
- `parent_id`: 父节点ID，用于构建树形结构
- `depart_name`: 部门名称
- `org_code`: 部门编码，关联设备的关键字段
- `org_type`: 组织类型 (1=一级部门, 2=子部门)
- `status`: 状态 (1=启用, 0=不启用)
- `del_flag`: 删除标识 (0=正常, 1=已删除)

#### tb_module (设备仪表表)

设备与部门的关联表，核心字段:
- `module_id`: 仪表编号
- `module_name`: 仪表名称
- `sys_org_code`: 所属部门编码，关联 `sys_depart.org_code`
- `energy_type`: 能源类型，用于区分不同能源
- `isaction`: 是否启用

#### tb_energy_ratio_info (能源比例信息表)

新的能源配置表，核心字段:
- `id`: 主键
- `isenergy_type`: 能源类型编码
- `energy_name`: 能源名称
- `energy_unit`: 计量单位
- `zbmxs_value`: 折标煤系数
- `tpfxs_value`: 碳排放系数
- `price_per_unit`: 单价

#### tb_energy_classification_summary (分类统计汇总表)

需要评估是否需要调整结构以支持设备级统计:
- 现有字段已包含 `org_code`, `energy_type`, `time_dimension` 等关键字段
- 需要明确: `org_code` 是否可以存储设备ID，还是需要增加 `module_id` 字段

#### tb_ep_equ_energy_daycount (日统计表)

实时数据来源:
- `module_id`: 仪表编号
- `dt`: 统计日期
- `energy_count`: 能耗值
- 峰谷平尖时段数据
