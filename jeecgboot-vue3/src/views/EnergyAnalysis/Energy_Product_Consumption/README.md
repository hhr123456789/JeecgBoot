# 产品单耗分析页面

## 📍 页面路径
```
jeecgboot-vue3/src/views/EnergyAnalysis/Energy_Product_Consumption/
```

## 📊 功能概述

产品单耗分析页面用于分析不同产品类型的能耗情况,重点关注**单位产品能耗**指标,帮助企业:
- 识别高能耗产品
- 优化产品结构
- 降低生产成本
- 提升能源效率

## 🎨 页面结构

### 1. 左侧树形菜单
- **功能**: 按产品分类层级展示
- **示例数据**:
  ```
  ├─ 铝型材产品
  │  ├─ 建筑型材
  │  │  ├─ 门窗型材
  │  │  └─ 幕墙型材
  │  └─ 工业型材
  ```

- **搜索功能**: 支持快速搜索产品类型

### 2. 顶部筛选区
- 时间维度选择: 日/月/年
- 日期选择器: 根据时间维度动态切换
- 查询按钮: 触发数据查询

### 3. 数据卡片区 (5个核心指标)

| 指标 | 说明 | 颜色主题 |
|------|------|---------|
| **总能耗** | 选定周期内的总能源消耗 (kWh) | 蓝色 |
| **总产量** | 选定周期内的总产品数量 (件) | 绿色 |
| **合格产量** | 选定周期内的合格产品数量 (件) | 绿色 |
| **合格率** | 合格产量 ÷ 总产量 × 100% | 黄色 |
| **单位产品能耗** | 总能耗 ÷ 合格产量 (kWh/件) ⭐ **核心指标** | 红色 |

### 4. 图表区域

#### 第一行 (左右布局)

**左侧: 产品能耗分布 (饼图)**
- 展示不同产品类型的能耗占比
- 环形饼图设计
- 支持鼠标悬停查看详情

**右侧: 产品单耗趋势 (折线图)**
- 展示不同产品的单耗随时间变化趋势
- 多条曲线对比
- 帮助识别单耗上升/下降趋势

#### 第二行 (左右布局)

**左侧: 产量与能耗对比 (双轴柱状图)**
- 左轴: 产量 (件)
- 右轴: 能耗 (万kWh)
- 直观对比产量与能耗的关系

**右侧: 产品单耗排名 (横向柱状图)**
- 按单位产品能耗从低到高排序
- 绿色 → 黄色 → 红色渐变
- 快速识别高能耗产品

### 5. 数据表格

## 🎯 核心业务逻辑

### 单位产品能耗计算公式
```
单位产品能耗 = 总能耗 ÷ 合格产量
```

**示例**:
- 总能耗: 3,568,200.50 kWh
- 合格产量: 5,096 件
- 单位产品能耗: 3,568,200.50 ÷ 5,096 = **700.08 kWh/件**

### 环比计算公式
```
环比 = (本期单耗 - 上期单耗) ÷ 上期单耗 × 100%
```

**示例**:
- 本期单耗: 686.19 kWh/件
- 上期单耗: 701.35 kWh/件
- 环比: (686.19 - 701.35) ÷ 701.35 × 100% = **-2.16%** ✅ (下降,节能)

## 🔗 后端API接口 (已完成)

### 1. 获取统计数据
```
GET /energy/product/statistics
```

**请求参数**:
```json
{
  "productCategory": "1-1",        // 产品分类编码
  "timeUnit": "month",             // 时间维度: day/month/year
  "startDate": "2024-01",          // 开始日期
  "endDate": "2024-06"             // 结束日期 (可选)
}
```

**响应数据**:
```json
{
  "code": 0,
  "data": {
    "totalConsumption": 8668433.80,
    "totalProduction": 12580,
    "qualifiedProduction": 12256,
    "qualificationRate": 97.42,
    "unitConsumption": 707.15
  }
}
```
